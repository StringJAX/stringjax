# Security Policy

## Supported versions

The latest released `0.1.x` series receives fixes during the pre-release phase.

| Version | Supported |
|---------|-----------|
| 0.1.x   | yes       |

## Reporting a vulnerability

Please report suspected vulnerabilities **privately** rather than opening a public
issue. Use GitHub's "Report a vulnerability" (Security Advisories) on the
repository, or email the maintainer. We aim to acknowledge reports within a few
working days and to coordinate a fix and disclosure timeline with you.

This is research software; while we take security seriously, please bear in mind it
is maintained on a best-effort, academic basis.
